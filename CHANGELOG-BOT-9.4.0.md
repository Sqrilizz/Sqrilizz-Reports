# Sqrilizz-Reports Bot Edition 9.4.0

## Requirements

- Minecraft/Paper 26.2+
- Java 25+
- Discord bot token, channel ID, and moderator permissions configured in `config.yml`

## Includes

This build contains every feature from Standard Edition, plus the Discord bot.

## Discord Bot Features

- New report cards with `Resolved` and `Not a Bug` / `False Report` buttons
- Moderator permission checks using Discord Administrator or configured role IDs
- Minecraft head thumbnail for the reported player or bug reporter
- Immediate interaction acknowledgement to prevent Discord timeout errors
- Finalized report cards display the status and moderator, then disable further actions
- Reporter notifications and Telegram moderation notifications are sent through the same status workflow

## Artifact

Use `Sqrilizz-Reports-Bot-Edition-9.4.0.jar`.
