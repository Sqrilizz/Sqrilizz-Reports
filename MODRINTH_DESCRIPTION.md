# Sqrilizz-Reports 11.0.0

Modern, network-ready report management system for Paper and Folia servers.

## Downloads

### Sqrilizz-Reports-Standard-Edition-11.0.0.jar
Recommended for most modern Paper and Folia servers. Lightweight build (~2 MB) with HikariCP connection pooling.

### Sqrilizz-Reports-Bot-Edition-11.0.0.jar
Bundled build with offline SQLite and MySQL JDBC drivers included.

### Sqrilizz-Reports-Velocity-11.0.0.jar / Sqrilizz-Reports-Bungee-11.0.0.jar
Optional proxy forwarders for multi-server networks.

## Requirements

- Minecraft: 26.3+
- Server: Paper, Purpur, or Folia
- Java: 25+

## Features

- Native Folia region scheduler compatibility
- Interactive moderation GUI with player heads, pagination, and quick actions
- Built-in bug report system with customizable categories
- SQLite and MySQL storage with HikariCP
- Discord Webhook and Telegram notifications
- Cooldowns, duplicate detection, and rate limits
- Multilingual support: English, Russian, Arabic
